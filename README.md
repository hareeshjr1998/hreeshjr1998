## About

I'm a backend developer at **Mind Vision Technologies**, focused on building and supporting server-side applications. My work spans API design, backend/frontend integration, cloud object storage, and application deployment.

- **Backend:** Node.js, Express.js, REST APIs
- **Storage:** AWS S3 and S3-compatible object storage
- **Infrastructure:** DigitalOcean, Hostinger, Linux server basics
- **Based in:** Madurai, Tamil Nadu, India
